# 1.5 コスト最適化と可視化の戦略(組織レベル)

## 試験で問われる観点

- 組織全体のコスト配分・可視化(タグ、CUR、Cost Explorer)
- 部門・アカウント単位のコスト統制(Budgets、SCP)
- 購入オプションの組織的な管理(RI/SP の共有)

※ワークロード単体のコスト設計は [2-6](../02-new-solutions/2-6-cost-optimization.md)、既存環境の削減は [3-5](../03-continuous-improvement/3-5-cost.md) を参照。

## コスト可視化のツールチェーン

| ツール | 用途 |
|---|---|
| **Cost Explorer** | GUI での分析・フィルタ・予測。RI/SP の**推奨事項** |
| **CUR (Cost and Usage Report)** | **最も詳細な明細**(リソース単位・時間単位)。S3 に出力 → **Athena + QuickSight** で分析(定番構成) |
| **コスト配分タグ** | 部門・プロジェクト別の按分。**有効化(activate)しないと請求データに現れない** |
| **Cost Categories** | タグ・アカウント・サービスを組み合わせた独自のコスト分類 |
| **AWS Budgets** | 予算超過(実績/予測)のアラート。**Budgets Actions で SCP 適用や IAM 制限を自動実行**可能 |
| **Cost Anomaly Detection** | ML による異常な支出の検知・通知 |
| **Billing Conductor** | 社内転売・独自レートでの請求グループ分け(プロフォーマ請求) |
| Compute Optimizer / Trusted Advisor | ライトサイジング・アイドル検出(3-5 参照) |

**定番の組み合わせ**: 「部門別のコストダッシュボードを作りたい」→ **コスト配分タグ + CUR + Athena + QuickSight**。「請求書レベルで分けたい」→ アカウント分割(+ Cost Categories)。

## タグ戦略(組織レベル)

1. **タグポリシー**(Organizations)でキー・値の標準を定義(違反の検出)
2. **SCP の `aws:RequestTag` / `aws:TagKeys` 条件**でタグなしリソースの作成を拒否(強制)
3. **コスト配分タグとして有効化**(管理アカウントで)
4. Tag Editor / Config ルール (`required-tags`) で既存リソースの是正

「タグの付与を強制したい」= タグポリシーだけでは**作成をブロックできない** → SCP と組み合わせる、が頻出の正解。

## RI / Savings Plans の組織管理

- 一括請求ファミリー内で **RI/SP の割引は自動共有**(未使用分が他アカウントに適用される)
- 特定アカウントに割引を独占させたい/会計を分けたい → **RI 割引共有をアカウント単位で無効化**
- 購入は一元管理(管理アカウントまたは専用アカウント)が推奨
- ボリューム割引(S3 等)も組織全体で合算される

## アカウント単位のコスト統制シナリオ

| 要件 | 解 |
|---|---|
| サンドボックスの使いすぎ防止 | Budgets アラート + **Budgets Actions**(閾値超過で SCP 適用・インスタンス起動権限剥奪) |
| 高額サービスの利用禁止 | SCP でサービス/インスタンスタイプを Deny(例: `ec2:InstanceType` 条件で大型を禁止) |
| 予期しない急増の検知 | Cost Anomaly Detection |
| 部門への請求転嫁 | コスト配分タグ / アカウント分割 / Billing Conductor |

## 頻出のひっかけポイント

- コスト配分タグは**有効化した時点以降**のデータにしか付かない(遡及しない)
- 「リソース単位・時間単位の詳細分析」→ Cost Explorer ではなく **CUR + Athena**
- Budgets は**アラートと自動アクション**まで。リアルタイムの強制停止はできない(Actions で権限剥奪はできる)
- RI/SP 推奨は Cost Explorer(組織全体視点と個別アカウント視点を選べる)
- 「メンバーアカウントに請求情報を見せたい」→ 各アカウントで Cost Explorer 有効化(IAM で billing アクセス許可)
