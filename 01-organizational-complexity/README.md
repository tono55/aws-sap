# Domain 1: 組織の複雑さに対応する設計(26%)

複数アカウント・複数 VPC・オンプレミス接続という「大規模組織」の前提で設計できるかを問うドメイン。
SAA との差が最も大きい領域で、**Organizations / SCP / Transit Gateway / Direct Connect** は SAP の代名詞的トピック。実務で触れる機会が少ない人が多いため、重点的に学習する。

## このドメインの攻略ポイント

- ネットワーク問題は「**何と何をつなぐか(VPC数・アカウント数・オンプレ有無)**」と「**帯域・冗長性・暗号化要件**」の2軸で選択肢が絞れる
- SCP は「**許可を与えるものではなく、上限(ガードレール)**」という原則を徹底理解する
- 「中央集権(セキュリティ/ネットワーク/ログ専用アカウント)」の定番アーキテクチャパターンを頭に入れる
