# Domain 3: 既存のソリューションの継続的な改善(25%)

## このドメインの攻略ポイント

- 「**既存構成の説明 → 問題点 → 改善策の選択**」という問題形式。まず現構成のアンチパターン(単一 AZ、手動運用、平文シークレット、gp2、オンデマンド常時稼働など)を見つける癖をつける
- 「最小の運用負荷で」「アプリに変更を加えずに」という制約が付くことが多い — マネージドサービスへの置換・設定変更だけで済む選択肢を優先
- 検知(Config/GuardDuty)→ 通知(EventBridge/SNS)→ **自動修復(SSM Automation/Lambda)** の3点セットを反射的に組めるようにする
